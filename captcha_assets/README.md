# 点选验证码 · 资源目录

放验证码图片所需的素材：

## icons/（图标）
放点选验证码的**目标图标** PNG（透明背景优先）。

- 一个文件一个图标，例如 `car.png`（小车）、`cat.png`（猫）
- 建议正方形、尺寸 64×64 以上（生成时会自动缩放）
- 生成器会从该目录随机选一个图标作为目标，做旋转/缩放/调色变体

## backgrounds/（背景图）
放验证码的**背景图**。

- 建议尺寸 **250×150**（与验证码画布一致）
- 透明 PNG 或普通图片均可
- 若此目录为空，生成器用纯色渐变占位

## 生成

```bash
cd xhl_sever
go run ./cmd/captcha_gen/
# 输出到 captcha_out/captcha_test.png，控制台打印答案坐标
```
